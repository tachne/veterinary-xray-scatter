# Veterinary X-ray Scatter Lab v0.2.2

獣医一般撮影を題材とする、単色一次X線の初回相互作用シミュレーター。撮影室の正面図で、被写体、撮影台、コリメータ周辺、空気を区別して散乱点・方向・エネルギーを観察できます。既存の他の実習アプリや外部APIに依存しません。

## 起動

Python 3.13。プロジェクトのルートで実行します。

```sh
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8521
```

[このPCで開く](http://127.0.0.1:8521/)。専用環境が既にある場合は最後の行を `.venv/bin/python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8521` として実行します。初回の依存環境構築後はオフラインで使用できます。

## 集束グリッドを試す

「集束グリッド」タブを開きます。初期条件は80 keV、被写体12 cm、照射野24 cm、入射20,000個、シード42、グリッド比8:1、SIDと集束距離は100 cmです。[撮影室の累積飛跡の比較画面](docs/room_grid_directions.jpg)

- **到達光子数・方向分布**：上部に、全計算標本で検出器面に到達した一次線・散乱線の数と、その内訳を表示します。内訳表で入射・透過・鉛箔吸収・側方退出を、方向分布で検出器に対する符号付きの投影角を比較できます。割合は光子数に基づきます。
- **撮影室の累積飛跡**　「グリッド再生の光子数」を400、「再生速度」を16倍にして再生します。左右の撮影室に同じ光子が順番に現れます。検出器に到達すると、その位置から薄緑の仮想領域に破線が伸び、再生後も残ります。一次線は灰色、散乱線は発生源の色です。破線は到達時の方向を表し、画面上の長さは全光子で共通です。鉛箔で止まる光子は赤い×が終点です。
- **グリッド〜検出器間を拡大**：濃い帯は鉛箔、白いすき間は中間物質。グリッド出口は検出器と同じ面（間隔0 mm）です。計算に基づく実線は、吸収なら鉛箔との最初の交点、通過なら検出器面で止まります。検出器面からの破線の長さに物理的な距離の意味はありません。
- 初期条件の拡大図では、**一次線の通過 #6**、**散乱線の吸収 #16**、**散乱線の通過 #57** を選べます。例示ボタンは現在の標本内の光子を選んで一時停止します。入口に入らない光子の再生中は、直近の入射光子の番号と断面を表示します。左右の撮影室全体と検出器の到達図は累積を保ちます。
- 一時停止・速度変更・拡大の開閉では履歴が残ります。シード連続は1→2→3の各最大400個、計1,200個。新しいシードに移ると、そのシードの飛跡と到達点の累積を始めます。「停止・先頭へ」で両側を消去します。
- 全標本から任意の光子番号を選ぶ断面図と、全標本・再生標本・集計の各CSVは従来どおりです。光子 #87 は一次線で、SID100 cmのまま集束距離を100 cmから70 cmへ変更するとカットオフを観察できます。

グリッドはy方向に一様な線状の構造で、焦点を原点とするx–z断面を扱います。透過数は保存済み方向を直線外挿した個数です。再散乱・散乱後の減弱を含む検出器信号や実測透過率は対象外です。条件と幾何学式は[モデルの説明](MODEL.md)に記載しています。

## 連続照射を試す

「撮影室と飛跡」→ **「連続再生」→「▶ 再生」**。固定シードが標準です。光子番号とシードを見ながら、一次線が発生点に到達し、コンプトン事象ではそこから矢印が伸びる様子を観察できます。一時停止はその時点を保持し、「停止・先頭へ」は最初の光子の入射前に戻ります。「連続再生する光子数」で各シード16・32・50・100・200・400本から選びます。静止図の表示本数は別に記憶します。「再生速度」は1・2・4・8・16倍の教育用表示速度です。

- 一次線を灰色、コンプトン散乱後の矢印を発生源ごとの色で累積します。進行中の光子は濃く表示します。再生を終えた後も同じシードの全飛跡が残り、一時停止・速度変更・撮影室とコリメータ拡大図の切り替えでも保持されます。「停止・先頭へ」で図とカウンターが0に戻ります。終了後にもう一度再生すると、新しい再生として先頭から始まります。
- 「再生済み」は選んだ光子の飛跡を最後まで描いた時点で1個、「累積飛跡」は現在のシードで一次線を描き始めた時点で1本を数えます。「うち散乱線」はコンプトン事象で方向の矢印を描いた本数です。図外も含む同じ光子は1回だけ数えます。番号を直接選択したときは、選んだ光子だけを追加します。
- 初期条件で各シード100本・16倍を選ぶと、固定シードは100本、シード1→2→3は計300本で終了します。シードが切り替わると図は次の標本の蓄積を始め、再生済みは通算します。シード42の「発生源別の例示」では終端で累積100本・散乱線100本、「入射番号順」では累積100本・散乱線36本です。[100本を累積した画面](docs/cumulative_100.jpg)
- 「入射番号順」で発生源を絞った連続再生は、該当する光子と無相互作用の一次線を入射番号順に指定本数まで選びます。該当数が少ない場合は存在する本数を表示します。
- 初期条件・シード42で「発生源別の例示」、32本、「コリメータ周辺を拡大」を選ぶと、#13（絞り羽根）、#19（照射野ミラー）、#31（出口カバー）、#57（付加フィルタ）を確認できます。発生点をクリックするか、図の下の「光子を選んで確認」で一時停止して詳細を読みます。[#19を選択した画面](docs/playback_mirror.jpg)。
- 「入射番号順」では #2（光電吸収）、#3（干渉性散乱）、#6（無相互作用）も確認できます。吸収と干渉性散乱では発生点で追跡終了。無相互作用なら検出器面まで進みます。該当する θ・E′ がない事象は「対象外」です。コンプトン散乱後の18 cmの矢印は既存の方向表示で、実際にその距離を透過したことを意味しません。
- 「シード連続（1 → 2 → 3）」では同じ物理条件・光子数の3標本から、各シード最大400本を準備します。再生を押すと標本を順に表示し、末尾で停止します。シード番号は物理時間ではありません。上部の計数と従来の全粒子・集計CSVは常にサイドバーのシードの値です。「再生対象の光子をCSV保存」だけは、再生順の行を全シード分収録します。元標本との対応は `seed_PCG64` と `photon_id` の組で確認できます。

## 試用

- 「撮影室と飛跡」：発生点、矢印、または粒子表で光子番号・部位・散乱角・散乱後エネルギーを確認します。「コリメータ周辺を拡大」は同じ座標の拡大です。初期条件と同じ[撮影室](docs/room.jpg)・[コリメータ](docs/collimator.jpg)の画面例があります。
- 「発生源別の例示」では各発生源のコンプトン事象を順に選びます。表示された矢印の本数比は発生率ではありません。「入射番号順」では相互作用しなかった光子、光電吸収、干渉性散乱も見られます。
- 「計数と分布」：物理条件とシードを固定した**全標本**の値を表示。発生源別、コリメータの部位別、エネルギー・角度の分布を確認できます。被写体厚0 cmは被写体を取り除く設定です。
- 「モデルと文献」：材料組成・密度・厚さ・XCOM部分係数、実測研究の測定位置と分母、適用限界を表示します。[物理モデル・出典](MODEL.md) ／ [数表の取得・再現方法](data/SOURCES.md)。

**CSV** はUTF-8 BOM付き。全粒子／表示中の粒子は1光子1行、集計は `aggregation=source` と `component` の2種です。全体集計に部位別行を足しません。入射エネルギー・照射野・厚さ・シード・光子数・モデル版を記録します。位置は焦点を原点とする cm。方向は(x,y,z)の単位ベクトル。算出対象外は空欄、数値0は計算で得た値です。干渉性散乱を無相互作用や光電吸収に含めません。

## テスト・配布

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

再生時計と進行段階のJavaScriptテストは `node --test tests/*.test.mjs`（Node.js 24で検証）。アプリの起動・配布にはNode.jsやJavaScriptのビルドは必要ありません。

[検証結果](TEST_RESULTS.md)。GitHub・Streamlit Community Cloud用には配布ZIPを展開し、フォルダの**中身**（`app.py`、`scatter/`［`player/`を含む］、`data/`、`.streamlit/`、依存ファイル、テスト、説明・図）をリポジトリのルートに置きます。教員の確認後に公開する場合のエントリーポイントは `app.py`、Pythonは3.13。秘密情報の設定は不要です。[Streamlit公式の公開手順](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy)
